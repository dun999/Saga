Questions worth asking first.

Is there really no database?
Saga itself stores nothing locally except your config. Every memory is SEAL-encrypted by the Walrus Memory relayer and written to Walrus mainnet as a blob owned by a Sui account. The relayer keeps a search index over those blobs, and Saga rebuilds it from Walrus with restore at boot — Walrus is the record.
Which agents can I use?
Claude Code, OpenAI Codex and Grok Build through their own CLIs and your existing subscriptions, plus any OpenAI-compatible API — OpenRouter, xAI, Groq, OpenAI, or a local model through Ollama or llama.cpp. Mention any of them with @.
What happens when an agent hits its limit?
Saga reads each provider's own usage windows. When one is exhausted — or the CLI isn't signed in, or the API is unreachable — the step is handed to your primary agent, and the chat shows the fallback so you always get a result.
How does it actually improve?
After a rating, a reflection pass reads the full trace and writes lessons for the agent involved. Successful multi-agent procedures become reusable skills. Critiques accumulate, and the system prompt evolves; each version is scored by your ratings and served by Thompson sampling, so a bad mutation loses traffic by itself.
Where do my API keys and sign-ins go?
They are encrypted on the Saga server with your vault key — a key your browser derives from a wallet signature and Saga never stores — so they can only be opened while you're signed in. They are never written to Walrus, and Disconnect deletes them. See Privacy & cookies.
Why C++?
One small binary with no runtime to install. Saga speaks the Walrus Memory protocol natively — Ed25519 request signing and SEAL session keys over libsodium — and its crypto is tested byte-for-byte against the official SDK.

Saga is a hackathon project for the Walrus “Chatbots That Remember” challenge. It drives third-party agents with your own accounts and keys; their usage is subject to each provider's terms and limits. Memories are stored on Walrus mainnet.

Saga uses only essential cookies — to keep you signed in and unlock your vault. No analytics, no ads. Privacy & cookies
